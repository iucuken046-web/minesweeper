# Сапёр

Браузерная версия классической игры. Цель — открыть все безопасные клетки. Число в открытой клетке показывает, сколько мин находится в восьми соседних клетках. Первый ход всегда безопасен.

## Как запустить

1. На GitHub нажмите **Code → Download ZIP**.
2. Распакуйте архив и откройте `index.html` в браузере. Сервер и установка зависимостей не нужны.

## Как играть

- Левый клик открывает клетку. Правый клик или клавиша **F** ставит или снимает флаг.
- На телефоне включите **Режим флагов** и коснитесь нужной клетки.
- С клавиатуры используйте стрелки для перемещения и **Enter** или **Пробел** для открытия.
- Доступны три поля — 9×9 с 10 минами, 12×12 с 22 минами и 16×16 с 40 минами.
- Таймер запускается при первом открытии клетки. Лучшее время хранится отдельно для каждого уровня в текущем браузере.

## Инструменты

- **HTML** — структура страницы и элементы управления.
- **CSS** — оформление, адаптивная сетка и состояния клеток.
- **JavaScript** — расстановка мин, открытие клеток, проверка победы, таймер и сохранение рекордов через `localStorage`.
